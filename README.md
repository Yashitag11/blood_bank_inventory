# Blood Bank Inventory Management System

A web-based Blood Bank Inventory Management System developed using **Django**, **MySQL**, **HTML**, and **CSS** to efficiently manage donor information and blood bank records.

The system provides a user-friendly interface for collecting and managing donor details, including name, age, date of birth, blood group, disease history, and parents' blood groups. Upon successful submission, donor data is securely stored in a MySQL database and users are redirected to a confirmation page.

Key features include:

* Donor registration and information management
* Secure storage of donor records using MySQL
* Record viewing page displaying all saved donor data
* Edit and update existing donor information
* Delete donor records when required
* Automatic synchronization of all CRUD (Create, Read, Update, Delete) operations with the database
* Responsive frontend built with HTML and CSS
* Backend development using Django framework

This project demonstrates full-stack web development concepts, database integration, form handling, data validation, and CRUD operations using Django and MySQL.
